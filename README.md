# Cybersecurity Labs

A hands-on cybersecurity laboratory documenting practical work in security operations, network security, vulnerability assessment, Linux security, and web application penetration testing.

## About This Repository

This repository documents cybersecurity labs and experiments conducted in controlled virtualized environments.

Each lab focuses on understanding the underlying security concepts, implementing relevant tools and techniques, analyzing results, and documenting findings, troubleshooting steps, and remediation approaches.

## Areas Covered

- Security Operations & Monitoring
- SIEM & Log Analysis
- Network Security
- Vulnerability Assessment
- Web Application Security
- Linux Security
- Password Security
- Offensive Security
- Security Automation

## Laboratory Environment

The labs are primarily conducted using virtualized environments with VMware and intentionally vulnerable or controlled systems.

### Technologies & Tools

Kali Linux | Ubuntu | Windows | VMware | Wazuh | Splunk | Nmap | Nessus | Wireshark | Metasploit | Gobuster | DIRB | Hashcat | Lynis | Chkrootkit | Rkhunter

## Security Disclaimer

All security testing documented in this repository is performed against systems owned by the author, intentionally vulnerable systems, or isolated laboratory environments for educational purposes.

No unauthorized systems are targeted.
